One sentence, 128 characters, pitching the Picky Router: a Wi-Fi router that whispers its password only to guests it likes, so you never crawl behind the sofa to read the sticker again. A ridiculous invention for the tiny everyday annoyance of hunting for the Wi-Fi password on the sticker under the router.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`. Pure Python standard library, deterministic — the same bytes on every run.
